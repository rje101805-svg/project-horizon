# P2S8 manual acceptance — tractor beam

P2S8 only on `work`; P2S1–P2S7 are accepted. No bots/later phases, deployment actions, Pages artifact rebuild, polished effects or gameplay redesign.

## Local setup

Pull `work`, run `npm ci`, then restart `npm run server` and `npm run dev` from that same checkout. Use the printed local client URL and `http://localhost:3001` server URL. Open visible A/B windows; use C for third-party damage and D for late spectating. A creates, B joins, A presses START MATCH. Confirm `Round … · active` before testing E: waiting intentionally retains the older combat sandbox but has no tractor or winner/draw evaluation.

E is an activation tap, not a hold. Only living human roster participants in ACTIVE may use it. Aim the ship nose toward the target, using the existing mouse/movement-facing controls. Movement-facing aim remains unchanged: direction keys rotate the nose to the movement direction. One activation acquires the nearest valid unclaimed human inside the cone. Missing/invalid presses do not consume cooldown; a successful acquisition does.

## Acceptance A–H

1. **A — basic grab:** Position B roughly 100–180 units directly in front of A. Give B full 100 HP/50 shield. A taps E. A sees TRACTOR ACTIVE, B sees TRACTOR LOCK and a subtle screen shake. B moves inward when idle. C/D must see the same nose-facing cone. F3 shows attacker/target, range/cone/LOS, pull, elapsed duration, continuous-lock progress and predicted victim force. Aliens and spectators cannot be targets.
2. **B — continuous-lock finisher:** Maintain the same valid lock for three uninterrupted server seconds. Check lock progress on both clients. Touching/overlapping or passing very close to A before three seconds MUST NOT kill B. At 2.9 seconds B remains alive; at 3.0+ seconds of valid attachment the server explicitly eliminates B, ignoring shield, health and protection. B becomes alien/dead through the existing lifecycle; with only A/B human, A wins. With A/B/C human and C still alive, the round stays active and B respawns as an alien normally. Beam, lock and shake clear. Ended locks/freeze/result last about six simulation seconds, then reset restores everyone as humans waiting for another host start.
3. **C — escapes and duration:** B thrusts effectively away; normal thrust exceeds pull. Verify both rearward/range escape and lateral/cone escape. A retains full normal thrust, steering, turning and boost; turn away to break the cone. There is no target-tracking orientation. Break before three seconds: B survives, progress clears completely, and the 15-second activation cooldown remains committed. A later activation starts at zero with no accumulated time. A valid uninterrupted lock normally finishes at three seconds; the existing five-second maximum remains a defensive ceiling, covered deterministically in Node tests. No automatic reacquisition. Deterministic timeout coverage is also in the Node tests.
4. **D — damage persistence:** Use A/B/C human. While A beams B, C shoots A and B shoots A. Shield-first damage applies and the beam continues. An alien can also damage A without releasing B. Only actual attacker elimination cancels the beam. Test victim elimination by another source as well: it clears the interaction without tractor finisher attribution.
5. **E — LOS deferred:** Manual LOS/obstacle testing is deferred to Phase 3. Decorative scenery is not collision geometry. `room.tractorLOS` is a server-only injectable predicate; current default is clear. Tests force blocked LOS at acquisition and during maintenance. In Phase 3, repeat acquisition/maintenance with a real blocking obstacle and verify clear paths allow grabs and newly blocked paths release victims while retaining cooldown.
6. **F — restrictions/cooldown:** E is unavailable while waiting/ended, dead, alien or spectator. Attacker can move/turn and reload but cannot shoot during a beam; rejected shots consume no ammo. Victim can shoot. A cannot reuse E until 15 seconds after successful activation, regardless of escape/timeout/capture/elimination. Normal nonlethal damage never breaks it. HUD shows READY, ACTIVE or remaining seconds only for living ACTIVE humans.
7. **G — cleanup:** During active beams test attacker/victim disconnect, elimination, match end and reset/new round. No stale target, pull, cone, lock or shake survives. Cooldown stays committed through cancellations and is cleared by the authoritative round reset. D remains immune OUT throughout its spectated round; after reset and host start it becomes a human eligible to use/be targeted by tractor. Repeat consecutive rounds with different attacker/victim identities.
8. **H — latency:** Enable existing visible DEV 150ms each-way fake-network controls with ±30ms jitter in every client. Repeat acquisition, predicted pull, rearward/lateral escape, turning and continuous-lock finisher. Victim movement should remain smooth and controllable with ordinary reconciliation; no repeated teleporting/snapping. All clients/spectators must agree on attacker/target and authoritative transitions. Disable and confirm OFF. Feel/tuning acceptance remains manual.

## Architecture and initial tuning

`shared/tractor.ts`: 220-unit range, 60° full cone, 200 units/s² pull acceleration, 3000ms continuous-lock kill threshold, full normal attacker thrust/steering/boost (P2S9 correction), 5000ms maximum duration, 15000ms cooldown. With the existing velocity response, idle terminal drag is approximately 32 units/s, below normal 290-unit/s deliberate thrust. Changing any balance value uses these centralized constants.

`server/tractor.ts` validates socket membership, monotonic sequence, membership session, round/life/teleport markers, ACTIVE living HUMAN roster eligibility, nearest cone/range target, unclaimed victim, LOS and cooldown. It owns private room beam records and simulation-time cooldown deadlines. Fixed tick validates before movement and again after the player/projectile damage batch, then runs the existing result evaluator. No new timer or physics loop. Ordinary damage has no cancellation hook; the explicit lethal transition cancels references immediately. A successful continuous-lock finisher calls that transition with a typed TRACTOR source, never giant damage.

Replicated per-player tractor state supplies attacker/target identity, remaining durations and authoritative pull anchor. `shared/movement.ts` adds the same pull acceleration to gravity without reducing attacker thrust or boost; server simulation and LocalPredictor tick/acknowledgement replay both use it. Client input never specifies a target or force. Existing movement aim, rates, interpolation, gun/reload, alien melee and prediction queues remain intact when tractor is inactive.

E requests share the existing epoch-guarded fake-input delay. Snapshots use the existing ordered fake snapshot delay. The client renders cones from ship nose/rotation using the same shared angle/range, on the existing scene update. Warning/shake, HUD and debug display authoritative interaction state; only movement is predicted. Match/lifecycle/disconnect cleanup rejects delayed old requests. No DEV tractor authority or public LOS override was introduced.

## Continuous-lock regression checks

The proximity kill threshold has been removed entirely. `TRACTOR_KILL_LOCK_MS = 3000` is measured from the current private beam record’s acquisition timestamp, after current cone/range/LOS/lifecycle validation. Clear discards that record and zeroes progress. Each later successful activation creates a new timestamp; elapsed time never accumulates between uses. Pull still uses the same shared movement/prediction code at 200 units/s². Tests verify overlap, one-unit separation, former 28-unit vicinity and ordinary range at 0–2999ms remain alive, exact 3000ms kills, 2.9-second breaks/reacquisition discard progress, and weak-pull normal thrust retains control. Browser tests verify progress and survival near 2.9 seconds before the finisher, including simulated latency.
