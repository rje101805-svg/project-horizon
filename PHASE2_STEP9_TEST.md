# P2S9 — FILL GAME + bot foundation manual acceptance

Start `npm run server` and `npm run dev`. Create a fresh room in the browser using the server URL. Use another browser/tab to join its code. F3 shows bot diagnostics in development; fake network controls remain outside F3. No COMBAT_DEBUG flag is needed for normal play. For controlled fixtures, only existing explicitly authorized DEV tooling is available; production still rejects it.

1. **Fill/authority:** Alone, verify 1 / 8, host FILL GAME, then exactly seven named [BOT] ships and 8 / 8. Repeat with three humans (five bots), seven (one), and eight (none). Full fill disables. Non-host has no fill/start buttons. Host departure transfers authority to a real human. Fill is unavailable ACTIVE/ENDED; repeated requests never exceed eight.
2. **Start/basic hands:** START MATCH includes all eight. Bots fly/turn/chase, strafe at medium distance, reposition close, boost far, aim/shoot, consume ammo/reload and switch invalid targets. They target humans and other bots, never spectators/aliens. F3 lists identity, status, mode/target, desired heading, distance, controls and combat actions.
3. **Tractor attack:** Arrange/approach a bot inside its forward cone. It may activate the normal beam, continues normal flight and cannot shoot while beaming. Verify 200 pull, 220 range, 60° cone, 3000ms continuous-lock kill, no touch/overlap kill, 15s committed cooldown and 5s safety ceiling. Nonlethal attacker damage leaves it attached; elimination cancels.
4. **Tractor escape:** Tractor a human-form bot several times. F3 shows TRACTOR_ESCAPE, outward/lateral boosted movement replaces chase. Fixed attacker aim should allow escape; pursue and track to earn a full three-second lock. Escape is neither guaranteed nor a free kill. On break, bot resumes HUNT, attacker retains cooldown. Repeat with bot-vs-bot. Verify no teleport/stat advantages.
5. **Alien bots:** Eliminate a bot via normal projectile/tractor/environment. It becomes a ghost/ALIEN, respawns after ~3s with 40 HP, no shield/ammo/gun/tractor and ~2s protection. It chases nearest living human-form participant and spam-melees for 5 within 60. Attacking ends protection. It cannot hit aliens, count as human, or win. Kill it again; normal alien respawn resumes chase.
6. **Winner/reset/repeat:** Let a bot become last human-form survivor; everyone sees its name WINS. Combat freezes for ~6s. Reset returns WAITING, bots retain IDs/names without duplication, all hulls/resources become human, modes/targets/escape/reload/tractor clear. Host must start again. Repeat with a real-human winner. Zero humans is DRAW through the accepted lifecycle.
7. **Human priority:** While WAITING at 1 human + 7 bots, join another human: immediate 2 humans + 6 bots, eight slots. While ACTIVE, join another: OUT spectator/JOINS NEXT ROUND, eight current participants unchanged. At reset remove one bot, admit queued human. Queue multiple humans and verify one bot replacement each and eight participants maximum. Queue bounded to eight real humans total; if no bots/full human room, join is rejected. Disconnect queued humans, verify no stale admission. Replaced bots leave no ships, bullets, beams or future roster entries.
8. **Tractor flight correction:** While human attacker beams, compare normal thrust, steering, turning and Shift boost to no-beam flight. Maintain target by flying and aiming. Fire stays blocked. Victim pull/prediction and all lock rules unchanged.
9. **Latency/performance:** Play meaningful 1 human + 7 bots combat with fake network OFF, then 150ms each way / ±30ms jitter ON. Verify usable prediction, responsive 30Hz server, bot firing/tractor/escape/aliens, winner/reset and no errors/log spam. Compare F3 FPS/tick telemetry with accepted P2S8; automated timing smoke is not a hardware FPS guarantee.
10. **Cleanup:** Leave every real-human browser; room and all bots/controllers are destroyed. Creating a fresh room starts at 1 / 8. No background bot timers/socket clients remain.
