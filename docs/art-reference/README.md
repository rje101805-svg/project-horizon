# P3S2 art direction

The owner supplied one conversation screenshot showing four lit reference spheres. It was inspected in the chat: ice cyan/white, volcanic black/molten orange, terrestrial teal/green/white clouds, barren silver/sandstone. Separate full-resolution source images and redistribution licenses were not supplied. No licensed image is committed or used as a runtime texture. The original screenshot remains in the owner's task attachment; a downloadable image file was not exposed in this workspace, so a local copy cannot be claimed.

Ice: fine fractures, bright white glaciers and rich frozen blues, cyan haze, clear terminator.
Volcanic: dark obsidian plates, branching irregular orange fissures emitting locally, fiery edge.
Terrestrial: organic continents and shelf coasts, deep blue water, turquoise shallows, separate moving white weather, blue limb.
Moon: varied overlapping impacts and basins, silver/sandstone regolith, relief, sharp shadow and no atmosphere.

Generated maps are original deterministic numerical artwork, not copies of the screenshot. See scripts/art/generate-planets.py and public/planets/. These are a procedural interpretation; manual comparison and refinement remain necessary.
